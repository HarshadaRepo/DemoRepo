# yt-automation

yt-automation is a private tool used only by the owner of this YouTube channel to upload videos to their own channel.

## Privacy policy

- **Who uses it:** only the channel owner. The tool is not offered to anyone else.
- **What it accesses:** permission to upload videos and set their details (title, description, thumbnail) on the owner's own YouTube channel, through the YouTube Data API.
- **What it stores:** a sign-in token, kept as an encrypted secret in the owner's private GitHub repository. It does not collect, sell or share any personal data.
- **Removing access:** the owner can revoke access at any time at https://myaccount.google.com/permissions.
- **Google policy:** use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
- **Contact:** use the email address on this channel's YouTube "About" page.
